STARFORGE DEFENSE — a bright 3D tower-defense game on a metal deck floating in a sunny sky. A captured living star powers every tower along a molten conduit, and void constructs ride that conduit inward to drink the star dry. Fifty designed stages, a stage-reward choice after every assault, NEW HOSTILE intel cards as new constructs debut, 4 tower types with level-3 specializations, STARFALL — the star hurling its own fire — and an endless mode beyond the final victory. Three.js is vendored under game/vendor/; everything else is original code in this repo.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 — or simply open game/index.html in a browser
```
